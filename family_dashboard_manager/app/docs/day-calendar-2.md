# Today, Calendar and Boys — 0.31.0

Today adds a decorative weather/day illustration and progress rings within the existing primary panels. Rings count only completed daily jobs and packing items; awaiting approval and unavailable data are not counted as done. The school-run panel, homework actions, tomorrow preparation and compact useful shortcuts remain available. Illustrations are hidden from assistive technology.

Calendar opens on the current date with a full seven-day view. Each day shows its event times, titles, people and packing progress. Tap an event for the existing details dialog, or tap a date/Day details for the selected day's agenda and shared checklist. Back to week returns to the full week. Month shows two event previews and an additional count in each date cell; selecting a date opens details and Back to month returns to the grid. Day and Agenda remain alternative modes. The date picker, Today and previous/next period controls remain visible.

Overnight and multi-day events appear on each day they occupy; all-day and midnight end dates stay exclusive. Continued timed events show Until with their finish time, or Continues for intermediate days. Event and reading drafts retain the existing keyboard-aware forms and bounded save paths. Person selections remain independent across Today, Calendar and Boys. No household configuration changes or new integrations are required.

Boys is the new visible name for the existing family section, including To do, Homework, Lunch and Rewards. Internal routing and stored preference keys are preserved for existing installations. The full dashboard remains the default; optional simple mode remains available.

Validation covers navigation, multi-day events, event creation and failed-save drafts, keyboard handling, shared packing updates, read-only restrictions, live refresh, portrait/narrow layouts, light/dark appearances and 200% zoom.
