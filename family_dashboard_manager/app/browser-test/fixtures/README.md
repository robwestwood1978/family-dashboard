# Browser review assets

`../mdi-fixture.json` contains the icon path subset used by the browser fixtures, extracted from Material Design Icons v7.4.47 (`@mdi/js`). It lets visual checks exercise the same distinct icon silhouettes as Home Assistant instead of substituting identical rectangles. The paths are unmodified; this file is a subset of the upstream collection.

Source: https://github.com/Templarian/MaterialDesign-JS

The upstream [Pictogrammers Free License](https://github.com/Templarian/MaterialDesign-JS/blob/master/LICENSE) distributes icon files under Apache 2.0 or their respective original licenses. A copy of Apache 2.0 is included in `LICENSE-MDI.txt`.

`review-album.svg` is original synthetic artwork for dashboard screenshots. It is representative preview content, not real household music artwork.
