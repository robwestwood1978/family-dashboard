# Family Dashboard Manager

Home Assistant app for confirmation-bound Family Dashboard deployment and hash-verified rollback. Version 0.9.0 upgrades the existing manager in place with namespaced navigation, a useful Home and Energy experience, equal Tottenham/Aston Villa treatment, a ChoreOps-aware Family overview, and deliberate exterior-camera viewing through Home Assistant's native live picture card. Controlled live actions remain limited to validated household mappings. Calendar and Classroom stay read-only, camera presentation remains exterior-only and one at a time, and garage/alarm changes require a fresh second confirmation. See [DOCS.md](./DOCS.md) for the upgrade and safety boundaries.
