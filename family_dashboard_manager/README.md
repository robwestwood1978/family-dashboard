# Family Dashboard Manager

Home Assistant app for confirmation-bound Family Dashboard deployment and hash-verified rollback. Version 0.7.3 upgrades the existing manager in place and makes deliberate exterior-camera viewing follow Home Assistant's real idle, preparing and streaming states without duplicate Eufy commands or stale players. Controlled live actions remain limited to validated household mappings. Calendar and Classroom stay read-only, camera presentation remains exterior-only and one at a time, and garage/alarm changes retain second confirmation. See [DOCS.md](./DOCS.md) for the upgrade and safety boundaries.
