# Family Dashboard Manager

Home Assistant app for confirmation-bound Family Dashboard deployment and hash-verified rollback. Version 0.7.1 upgrades the existing manager in place, adds explicit current/target heating presentation and bounded thermostat power controls, and retains controlled live actions only for validated household mappings. Calendar and Classroom stay read-only, camera presentation remains exterior-only and deliberate, and garage/alarm changes retain second confirmation. See [DOCS.md](./DOCS.md) for the upgrade and safety boundaries.
