# Family Dashboard Manager

Home Assistant app for confirmation-bound Family Dashboard deployment and hash-verified rollback. Version 0.12 adds an administrator-only ingress panel for complete non-secret household setup, a child-first Tasks experience with exact ChoreOps claim actions, and configurable favourite football clubs. Calendar writes remain restricted to explicitly writable mappings, preparation writes to one configured to-do list, and Classroom remains read-only and optional. Camera presentation remains exterior-only and one at a time, while garage/alarm changes require a fresh second confirmation. See [DOCS.md](./DOCS.md) for the upgrade and safety boundaries.
