# Family Dashboard Manager

Home Assistant app for confirmation-bound Family Dashboard deployment and hash-verified rollback. Version 0.11.1 repairs and completes the colour-coded Family Planner with first-party Day, Week, Month and Agenda views, period navigation, explicit refresh and editable event-linked **Ready** checklists. Calendar writes remain restricted to explicitly writable mappings, preparation writes to one configured to-do list, and Classroom remains read-only and optional. Camera presentation remains exterior-only and one at a time, while garage/alarm changes require a fresh second confirmation. See [DOCS.md](./DOCS.md) for the upgrade and safety boundaries.
