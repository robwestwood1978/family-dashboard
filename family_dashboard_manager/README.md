# Family Dashboard Manager

Home Assistant app for confirmation-bound Family Dashboard deployment and hash-verified rollback. Version 0.10.0 retains the v0.9 controlled-live surface and adds a private Home Assistant media-source photo frame with motion return plus an honest calendar-only School fallback while Workspace approval is pending. Controlled live actions remain limited to validated household mappings. Calendar and Classroom stay read-only, camera presentation remains exterior-only and one at a time, and garage/alarm changes require a fresh second confirmation. See [DOCS.md](./DOCS.md) for the upgrade and safety boundaries.
