# Family Dashboard Manager

Home Assistant app for confirmation-bound Family Dashboard deployment and hash-verified rollback. Version 0.11.2 adds an urgent **Ready next** queue to Today, repairs the Spurs/Villa derby presentation and standardises touch selectors while retaining the complete colour-coded Family Planner. Calendar writes remain restricted to explicitly writable mappings, preparation writes to one configured to-do list, and Classroom remains read-only and optional. Camera presentation remains exterior-only and one at a time, while garage/alarm changes require a fresh second confirmation. See [DOCS.md](./DOCS.md) for the upgrade and safety boundaries.
