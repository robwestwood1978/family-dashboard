# Family Dashboard Manager

Home Assistant app for confirmation-bound Family Dashboard deployment and hash-verified rollback. Version 0.7.2 upgrades the existing manager in place, gives measured room temperature clear priority on each heating card, and makes Security fail visibly and safely when mapped entities are unavailable or unsupported. Controlled live actions remain limited to validated household mappings. Calendar and Classroom stay read-only, camera presentation remains exterior-only and deliberate, and garage/alarm changes retain second confirmation. See [DOCS.md](./DOCS.md) for the upgrade and safety boundaries.
