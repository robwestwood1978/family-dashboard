# Family Dashboard Manager

Home Assistant app for confirmation-bound Family Dashboard deployment and hash-verified rollback. Version 0.8.0 upgrades the existing manager in place, restores adaptive live football updates and keeps deliberate exterior-camera viewing covered until Home Assistant's native player supplies its first frame. Controlled live actions remain limited to validated household mappings. Calendar and Classroom stay read-only, camera presentation remains exterior-only and one at a time, and garage/alarm changes retain second confirmation. See [DOCS.md](./DOCS.md) for the upgrade and safety boundaries.
