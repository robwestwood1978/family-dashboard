# Family Dashboard Manager

Home Assistant app for confirmation-bound Family Dashboard deployment and hash-verified rollback. Version 0.11.0 adds a colour-coded Family Planner, bounded Apple Calendar event creation and event-linked **Ready** checklists while retaining the v0.10.1 kiosk repair. Calendar writes are restricted to explicitly writable mappings, preparation writes to one configured to-do list, and Classroom remains read-only and optional. Camera presentation remains exterior-only and one at a time, while garage/alarm changes require a fresh second confirmation. See [DOCS.md](./DOCS.md) for the upgrade and safety boundaries.
